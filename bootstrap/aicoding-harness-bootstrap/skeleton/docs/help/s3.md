# 对象存储 S3

> 读者：PM（design 确定存储端点与路径前缀）· Developer（实现前）· Reviewer（审查对照）
> 本篇受 [index.md](index.md)「通用约定」与「受保护/慎用清单」约束——示例即按封装层规范写。

## 概述

`sunny-base-s3`：附件、电子表格、图片等文件的统一存储。内部有两个 S3 端点：

- 原生 Amazon S3：`https://obs.sunnyoptical.cn`
- Vestack S3：`https://tos-s3.vestack.sunnyoptical.cn`

**新项目统一使用 Vestack S3（`VestackS3Service`）**；已有 Amazon S3 的项目可继续用 `AmazonS3Service`。

## 依赖

```xml
<dependency>
    <groupId>com.sunny</groupId>
    <artifactId>sunny-base-s3</artifactId>
</dependency>
```

版本由 base-platform 父 POM 统一管理，禁止子模块私改。

## 配置

- 测试和开发环境共用同一个 S3 账户和桶
- 必须设置 `pathPrefix`（路径前缀）隔离各项目文件路径，建议取项目名（`cusparam.system-name`）
- 新项目用 `vestacks3-config` 配置，不建旧的 `amazon-config`

## 使用方式

### 封装层（模块专属子目录，response 处理收在封装内）

```java
// customerlib/file/FileStorageService.java —— 模块专属封装层（通用约定 1/3 条）
@Slf4j
@Service
public class FileStorageService {

    /** 上传文件：返回全路径（自动生成日期目录，如 2023-07-12/文件名_20230712104520123.xlsx），调用方保存到业务表 */
    public String upload(MultipartFile file) {
        try {
            String path = VestackS3Service.uploadFile(file);
            log.info("s3_upload_ok path={}", path);
            return path;
        } catch (Exception e) {
            log.error("s3_upload_failed fileName={}", file.getOriginalFilename(), e);
            throw new BusinessException("文件上传失败");
        }
    }

    /** 下载文件：response 获取收在封装层，业务层不碰 Servlet API */
    public void download(String path, String fileName) {
        try {
            ServletRequestAttributes attrs = (ServletRequestAttributes) RequestContextHolder.getRequestAttributes();
            HttpServletResponse response = attrs.getResponse();
            VestackS3Service.download(response, path, fileName);
            log.info("s3_download_ok path={}", path);
        } catch (Exception e) {
            log.error("s3_download_failed path={}", path, e);
            throw new BusinessException("文件下载失败");
        }
    }
}
```

### 业务层使用（Service 内，Controller 只编排）

```java
// 业务 Service：上传后把路径落到业务表
@Service
public class AttachmentService {

    @Autowired
    private FileStorageService fileStorageService;

    public Result<?> uploadAttachment(MultipartFile file, String bizId) {
        String path = fileStorageService.upload(file);
        attachmentMapper.insertPath(bizId, path);  // 路径保存到业务表，供后续下载
        return Result.ok(path);
    }

    public void downloadAttachment(String bizId) {
        Attachment att = attachmentMapper.getByBizId(bizId);
        fileStorageService.download(att.getPath(), att.getFileName());
    }
}
```

## 注意事项

- 后端返回的文件名经过 `URLEncoder.encode` 编码，前端接收时需 URL 解码
- 上传返回的路径必须保存到业务表，否则文件失联
- 文件上传属外部资源操作，大批量场景在 design.md 说明大小/数量上限与失败处理
