## 文档结构（六段）

1. **头部路由块**（紧跟标题的引用块）：读者三角色（PM · Developer · Reviewer）+ 受 index.md「通用约定」与「受保护/慎用清单」约束的引用行
2. **概述**：包名 + 一句话能力定位 + 何时用它（场景触发词，供路由判断）
3. **依赖**：Maven 坐标 groupId + artifactId（**不写 version**——版本由 base-platform 父 POM 统一管理）
4. **配置**：yml / 系统管理配置项 + 关键配置说明表（无配置项可省略本段）
5. **使用方式**：代码示例一律 **Service / 封装层语境**——通用约定 1/3 条：封装进模块专属子目录，禁止 Controller 直调、禁止裸抛异常
6. **注意事项**：能力专属坑；通用红线不重复，引用 index.md

## 写作红线

- 示例不得出现 Controller 直调平台工具类（演示 API 形态也不行——会被照抄）
- 依赖示例不写死 SNAPSHOT 版本号
- 超时/重试/降级不写死在文档——提示 design.md 显式声明（通用约定 4 条）
- 凭据永不入文档（地址可写，账号/密码/token 不写）
- 日志示例用类级 `@Slf4j`（对齐宪法日志规范）
