# 表详情文件模板（tables/<域>.md）

> 每个域一个文件（如 `mdm.md` / `platform.md` / `_unmapped.md`），由数据字典导出结果按本模板格式化生成。
> 本文件是**格式规范**，不是交付物——填充时复制下方结构，删除说明性文字。

---

## 文件头（每个域文件必备）

```markdown
# {域} 域表详情

> {域职责一句话}。共 {N} 张表。数据源与导出时间见 ../index.md。

## 表清单

| 表名 | 行数估算 | 说明 |
|---|---|---|
| {TABLE_NAME} | {N} | {表注释} |
```

## 每表详情（逐表一节）

```markdown
### {TABLE_NAME}（{表中文注释}）

- 行数估算：{N}

#### 字段

| 列名 | 类型 | 长度 | 精度 | 标度 | 允许空 | 默认值 | 注释 |
|---|---|---|---|---|---|---|---|
| {COLUMN_NAME} | {TYPE} | {LEN} | {PRECISION} | {SCALE} | {Y/N} | {DEFAULT} | {列注释} |

#### 主键

- {约束名}（{主键列}；有序列/触发器则一并注明}

#### 唯一索引

- {索引名}（{列}）／ 无则写「（无）」

#### 普通索引

- {索引名}（{列}）／ 无则写「（无）」

#### 外键

- {约束名}（{列} → {引用表}.{引用列}）／ 无外键约束的库统一注明「外键 0 条（关系由应用层维护）」
```

---

## 生成规则

<!-- 分析指引：由 aicoding-db-schema-export skill 的固定脚本导出生成；以下规则生成时逐条遵守 -->

1. **禁止手敲字段**——全部来自脚本导出的 JSON（数据字典查询内嵌于 skill 的 `scripts/dump_schema.py`，支持 Oracle / PostgreSQL / MySQL / SQL Server），防止幻觉字段
2. 说明列取表/列注释，无注释留空（不要编造业务含义；确知的含义先补进数据库注释再导出）
3. 行数估算来自统计信息（`num_rows` / `table_rows`），标注「约」；小表可精确 count
4. 表排序：按表名字母序；域内超 60 张表时拆分为 `<域>-2.md` 并在 `../index.md` 注明
5. 含敏感数据的表（密码、凭据类）在说明列标注「⚠️ 敏感」，字段注释不得展开真实值
