# database-snapshots — 表结构自用副本

## 口径（design.md §9.4）

| 情况 | 口径 |
|---|---|
| 原仓库已有 `docs/database/`（通用链生成） | **只读引用**它，不在本目录重复建 |
| 原仓库没有 | Report-PM 澄清时向用户索取表结构；高频用表由 PM 将 DDL/字段说明整理为快照写入本目录 `<域>.md`（自用副本，只增不改原仓库）；系统性全量导出建议到通用链工作区跑 `aicoding-db-schema-export`（其产物落 `docs/database/`，报表链只读受益） |

## 快照文件要求

- 文件名 `<域>.md`（如 `order.md`）；开头注明**来源与日期**（何人何时提供 / 出自哪个库）
- 只增不改：过时表结构新开小节追加，不删除历史
