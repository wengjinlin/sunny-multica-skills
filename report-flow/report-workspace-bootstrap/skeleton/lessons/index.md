# 报表链 lessons（自持，不动通用链 docs/lessons/）

历史踩坑视同约束。条目由 Report-DevOps 随 change 的 feature 分支 commit 批量落盘（一个 commit）；格式三行，不强制稳定 ID。

## 格式

```markdown
- [日期] [change-id] 一句话
  - ❌ 实际做法（踩坑）
  - ✅ 正确做法
```

## 角色文件

按角色建 `{Report-PM|Report-Developer|Report-Reviewer|Report-DevOps}.md`，首个条目落盘时创建；提炼触发硬门与巡检联动规则见编排层巡检剧本。
