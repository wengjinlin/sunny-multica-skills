# 报表宪法增量（docs/report-flow 模块说明）

## 定位

本目录是**报表专用工作区**的 harness 增量。与主宪法的关系：主宪法（仓库根 `CLAUDE.md`，若存在）管项目事实，本模块只补报表链专用规则——适用边界 / 单工件制（report-design.md） / 零侵入写面 / 归档路径。设计权威源见工作区 skill 仓库 `report-flow/design.md`。

## 适用边界（判定即分流）

**走报表链**：
- 新报表页面（查询现有表/视图 → 列表展示 → 导出）
- 存量报表加查询条件 / 加列 / 改导出配置
- 报表菜单与按钮权限注册

**不走（到通用链工作区发起）**：
- 涉建表 / 视图 / 加字段 / 加索引（有 DDL）
- 非查询展示类（业务流程编排、表单提交类页面）
- 跨多模块大型变更
- BUG 修复

判定责任：Report-PM 澄清阶段判定；判不了或命中「不走」清单 → chat 结论中明确建议到通用链工作区发起（澄清结论可复用）并停住。

## 写面声明

| 类别 | 范围 | 规则 |
|---|---|---|
| ✅ 写面 A：业务代码 | `src/` 等业务代码（新增页面/接口） | 任务本身，照常开发，经 MR 合并 |
| ✅ 写面 B：harness 增量 | `docs/report-flow/**`（本目录） | 报表链全部工件 / 文档 / 归档 / lessons 只写这里 |
| ❌ 禁改面 | 仓库其他一切已有文件与目录：`CLAUDE.md`、`AGENTS.md`、`REVIEW.md`、`docs/architecture/**`、`docs/database/**`、`docs/CHANGELOG.md`、`docs/lessons/**`、`docs/templates/**`、`openspec/**`、`.claude/**`（hooks）、`.gitlab-ci*` 等一切配置 | **一律只读**：可引用其内容作为权威源，但禁止修改、禁止 append、禁止 rename |

## 冲突裁决

本模块与主宪法冲突时：项目事实类（技术栈 / 方言 / 规范）以主宪法为准；流程类（工件 / 路径 / 审查方式）以本模块为准。
